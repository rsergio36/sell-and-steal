# SELL & STEAL

A fast-paced Roblox multiplayer game where you **collect, sell, upgrade, and steal** valuable loot.

## MVP loop

1. Collect loot.
2. Fill your bag.
3. Return to your plot.
4. Sell the loot for cash.
5. Upgrade capacity and collection speed.
6. Compete with other players.

## Development

This project is structured for [Rojo](https://rojo.space/) and Roblox Studio.

```
src/
├── client/
├── server/
└── shared/
```

The first milestone focuses on a small, playable economy loop before adding advanced stealing and live events.
